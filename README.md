## What I do

- **AI agents with manners.** Tool-calling LLM agents that ask for approval before they send or spend anything.
- **Data plumbing.** Resumable, polite scrapers and pipelines that feed agents clean data.
- **Business brain.** I co-founded a strategy consultancy, so I start from the problem and work back to the model.
- **Teaching.** Data Analysis, Data Science and AI Engineering tracks at Arabian Academy.

> Most of my agent work is under NDA, so what you see below is my own and my teaching projects.
